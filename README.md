# SenangStart CSS

A utility-first CSS framework that replaces abstract naming conventions with Natural Adjectives.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE.md)

## Quick Start

### CDN (Zero Build)

```html
<script src="https://unpkg.com/@bookklik/senangstart-css/dist/senangstart-css.min.js"></script>

<div
  layout="flex col center"
  space="p:big"
  visual="bg:primary text:white rounded:big"
>
  Hello SenangStart!
</div>
```

### CLI

```bash
npm i @bookklik/senangstart-css
senangstart init            # or: sen init — creates senangstart.config.mjs (.js in "type":"module" packages)
senangstart dev             # watch content globs + config, rebuild on change
senangstart build --minify  # production build (exit 1 on invalid tokens)
```

Both `senangstart` and `sen` bin aliases are available. Requires **Node ≥ 20**.

Useful flags:

| Flag | Purpose |
|------|---------|
| `-c, --config <path>` | Config file (relative or absolute). Missing/broken config → exit 1. Auto-discovers `senangstart.config.{js,mjs,cjs,json}` (and `.ts` on Node with type stripping). |
| `-o, --output <path>` | CSS output path (relative or absolute) |
| `--content <glob...>` | Override content globs (`!pattern` negation supported) |
| `--safelist <token...>` | Always emit these tokens, e.g. `flex p:medium visual=bg:primary` |
| `--ignore-invalid` | Warn instead of failing on invalid tokens |
| `--no-preflight` | Skip the base reset |
| `--json` | Machine-readable build summary on stdout |
| `-q, --quiet` / `--verbose` / `--no-color` | Logging control (`NO_COLOR` env is respected; warnings/errors go to stderr) |

Link the generated stylesheet in your HTML:

```html
<link rel="stylesheet" href="./public/senangstart.css">
```

> The build **fails on invalid tokens** by default and prints `file:line token → message`. Use `--ignore-invalid` to warn instead.

### Configuration

```js
// senangstart.config.mjs
export default {
  content: ['./**/*.html', './resources/**/*.blade.php', '!./legacy/**'],
  safelist: ['flex', 'visual=bg:primary', { attr: 'space', tokens: ['p:medium'] }],
  output: {
    css: './public/senangstart.css',
    minify: true,
    aiContext: null,      // opt-in: './.cursorrules'
    typescript: null      // opt-in: './types/senang.d.ts'
  },
  layers: true,           // cascade layers (@layer)
  preflight: true,
  darkMode: 'media',      // 'selector' | ['selector', '.dark'] | false
  build: { ignoreInvalid: false },
  theme: {
    exposeAll: false,
    colors: { brand: '#38BDF8' },            // deep-merged into defaults
    extend: { spacing: { huge: '256px' } }   // Tailwind-style extend (wins over direct keys)
  }
};
```

`aiContext` / `typescript` are **opt-in**. Generated files carry a `generated by SenangStart CSS` marker; an existing file without the marker is never overwritten. Unknown keys produce warnings, wrong types fail the build (`validateConfig`).

### Programmatic API (Node, ESM)

```js
import { build, watch, loadConfig, defineConfig } from '@bookklik/senangstart-css/node';

const result = await build({
  cwd: process.cwd(),           // project root
  config: 'senangstart.config.mjs', // path or a config object; omit to auto-discover
  content: ['./src/**/*.html'], // optional override
  output: false,                // false = don't write; string = CSS path
  minify: true,
  safelist: ['flex']
});
// result: { css, errors, warnings, files, outputs: { css?, aiContext?, typescript?, skipped }, durationMs, ok, tokenCount, config, configPath }

const watcher = await watch({ cwd }, (result, error, meta) => { /* meta.event: initial|add|change|unlink|config */ });
await watcher.close();
```

`build()` throws `ConfigError` (missing/invalid config) or `BuildError` (no sources, generation failure). The CLI is a thin wrapper over this API. Integrations: `@bookklik/senangstart-css/vite`, `@bookklik/senangstart-css/postcss`; JSON schema at `@bookklik/senangstart-css/schema`.

## Tailwind CSS Converter

Migrate from Tailwind with the built-in converter (ships in the package since 0.4.0):

```bash
npx senangstart convert input.html -o output.html      # one file
npx senangstart convert "resources/views/**/*.blade.php" --write   # in place
npx senangstart convert --string '<div class="flex p-4 md:hover:bg-blue-500">'
```

**Before (Tailwind):**
```html
<div class="flex items-center p-8 bg-blue-500 text-white rounded-lg md:dark:hover:bg-blue-600">
```

**After (SenangStart):**
```html
<div layout="flex items:center" space="p:large" visual="bg:blue-500 text:white rounded:medium tw-md:dark:hover:bg:blue-600">
```

Stacked variants, `!important`, `max-*`, `@container`, `aria-*`/`data-*`/`has-[]`, `group-*`/`peer-*`,
arbitrary values and arbitrary properties are converted. Classes SenangStart cannot express stay in
`class=""` and are listed at the end. Comments, `<script>`/`<style>` content, `data-class` and dynamic
bindings are left untouched.

### Exact mode

`--exact` keeps Tailwind's numeric scale so the result renders pixel-identically (`p-4` → `p:tw-4`,
`rounded-lg` → `rounded:tw-lg`). Without it, values map to SenangStart's semantic scale (`p-4` → `p:medium`).
A Playwright **conformance suite** (`npm run test:conformance`) renders Tailwind markup with Tailwind v4 CSS
and the exact-mode conversion with SenangStart CSS and compares computed styles.

Programmatic and browser use:

```js
import { convertHTML, convertClasses } from '@bookklik/senangstart-css/converter';
// browser: <script src="https://unpkg.com/@bookklik/senangstart-css/dist/senangstart-tw.min.js"></script>
//          window.SenangStartTW.convertHTML('<div class="flex p-4">Hi</div>')
```
