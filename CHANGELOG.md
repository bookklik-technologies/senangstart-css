# Changelog

## [Unreleased] — 0.4.0

### ⚠ BREAKING
- **Side outputs are opt-in.** `output.aiContext` and `output.typescript` now default to `null`. The default build no longer writes `./.cursorrules` or `./types/senang.d.ts`. Set them explicitly to re-enable. Generated files start with a marker line (`/* generated by SenangStart CSS — do not edit */` or `# generated by SenangStart CSS — do not edit`); an existing file **without** the marker is never overwritten (an error is printed, the file is skipped, the CSS build still exits 0).
- **Config errors fail the build.** A `--config` path that is missing or fails to load, an auto-discovered config that throws, or a config with wrong types (`validateConfig`) now exits with code 1. The CLI never silently falls back to defaults when a config exists.
- **Node ≥ 20** (`engines.node: ">=20.0.0"`). Node 18 is no longer supported. CI runs on 20/22/24.
- **`./cli` export is side-effect free.** `@bookklik/senangstart-css/cli` now resolves to `src/cli/program.js` (exports `program`, `createProgram`, `getVersion`) and no longer runs `program.parse()` on import. The `senangstart` / `sen` bins are unchanged.
- **Default `content` globs widened** to `html, php, blade.php, js, jsx, ts, tsx, vue, svelte, astro, md, mdx` (node_modules/.git/dist are ignored automatically).
- **Deterministic `@layer` output** (engine team): utilities are emitted inside cascade layers in a stable order; toggle with the new `layers` config field.
- `init` now writes **`senangstart.config.mjs`** (ESM) unless the nearest `package.json` has `"type": "module"` (then `.js`). Use `--js` to force `.js`, `--force` to overwrite.

### Added
- **Programmatic API** `@bookklik/senangstart-css/node` (ESM-only): `build(options)`, `watch(options, onResult)`, `loadConfig(pathOrObject, options)`, `defineConfig(cfg)`, plus `ConfigError` / `BuildError`. The CLI `build`/`dev` commands are thin wrappers over it.
- **Config**: `safelist` (raw tokens, `attr=token` strings or `{ attr, tokens }`; appended to the token set before generation), `prefix` (reserved, variant engine), `layers`, `theme.exposeAll` (engine), and `theme.extend` (Tailwind-style; merges into the base theme and wins over direct keys — previously silently ignored). `mergeConfig` deep-clones via `structuredClone`; `defaultConfig` is deeply frozen. New `validateConfig(config) → { errors, warnings }` — unknown keys warn, wrong types error; the CLI prints both.
- **Config discovery**: `senangstart.config.{js,mjs,cjs,json}` (+ `.ts`/`.mts` on Node runtimes with type stripping). Paths are `path.resolve`d, so absolute paths and configs outside cwd work. Config factories (`export default () => ({...})`) are supported. Watch mode cache-busts ESM imports so config edits apply without restart.
- **Globs via tinyglobby**: negation (`!pattern`), literal paths, brace expansion, multi-dot extensions (`*.blade.php`), nested dirs; symlinks are not followed.
- **CLI flags**: `--quiet`, `--verbose`, `--json` (machine-readable build summary on stdout), `--no-color`, `--content <glob...>`, `--safelist <token...>`, `--cwd <dir>`, `-c/--config`. `-o/--output` accepts absolute paths.
- **Diagnostics**: `file:line token (attr) → message (did you mean X?)` with a summary count; handles both the legacy token shape (`.raw/.error`, `{ type, token, message }`) and the new structured `{ raw, attrType, code, message, suggestion? }`. `--ignore-invalid` downgrades to warnings.
- **Logger**: warnings/errors go to stderr; respects `NO_COLOR`, `FORCE_COLOR=0`, `TERM=dumb` and non-TTY streams (no ANSI in CI logs).
- **Dev mode**: watches exactly the resolved `content` globs plus the config file (chokidar v3), debounced, re-creates the watcher when `content` changes, prints errors without crashing, clean SIGINT/SIGTERM shutdown.
- **Packaging**: export map entries `./node`, `./cli`, `./vite`, `./postcss`, `./schema`, `./dist/*`; `sideEffects` list; `size-limit` config (`dist/senangstart-css.min.js` ≤ 70 KB gzip, `dist/senangstart.min.css` ≤ 30 KB gzip); scripts `size`, `golden`, `typecheck`, `lint:all`, `test:packaging`; quoted recursive test globs; `.npmignore`; `publishConfig` with provenance.
- **CI**: Node 20/22/24 matrix (test → golden → docs sync → build:dist → size → typecheck), publint + `npm pack --dry-run`. **Release** workflow publishes on `v*` tags with `npm publish --provenance --access public` (requires the `NPM_TOKEN` repository secret; verifies the tag matches `package.json` version).
- Tests: `tests/unit/config-merge-validate.test.js`, `tests/unit/cli-*.test.js`, `tests/integration/cli-process.test.js` (real CLI via `child_process`), `tests/integration/cli-node-api.test.js`, `tests/packaging/manifest.test.js`.

### Fixed
- `scripts/generate-docs.js --compare` falsely reported the Malay `transition-property` docs as missing `colors`: the table parser skipped any row containing the word "Properti" (the description of that row is "Properti warna"). Header detection now inspects only the first cell.
- `-o` / `output.css` / `--config` used `path.join(process.cwd(), …)`, breaking absolute paths and rejecting configs outside cwd.
- Hand-rolled glob parser ignored negations, literal paths and multi-dot extensions.
- `mergeConfig` returned an object sharing nested references with `defaultConfig`, so consumers could mutate the defaults.

## [0.3.0] — 2026-05-16

### Fixed
- **CRITICAL:** Fixed uncaught `ReferenceError` in `src/utils/common.js` — `logger` imported without being required, causing runtime crashes on memory-limit batch processing.
- **Version sync:** `scripts/build-dist.js` and `src/cli/index.js` now read version dynamically from `package.json` (fixes banner showing `v0.2.0` and CLI showing `1.0.0` while actual version was `0.2.12`).
- **CLI build:** `findFiles()` now respects user's `config.content` glob patterns instead of ignoring them and walking the entire CWD with hardcoded extensions.
- **Build exit codes:** `senangstart build` now exits with code `1` on failure (no files found, all files fail, tokenization failure, CSS generation failure, write failures) so CI/CD pipelines correctly detect failures.
- **TW scale consolidation:** `src/compiler/generators/css.js` now imports Tailwind scales (`TW_SPACING`, `TW_RADIUS`, `TW_SHADOW`, `TW_FONT_SIZE`, `TW_LEADING`, `TW_FONT_WEIGHT`) from `src/core/constants.js` instead of hardcoding ~70 lines of duplicated data.

### Added
- **Source maps:** Enabled `sourcemap: true` on all esbuild dist bundles (`senangstart-css.js`, `senangstart-css.min.js`, `senangstart-tw.js`, `senangstart-tw.min.js`).
- **JIT engine debounce:** Added 200ms debounce on `MutationObserver` callback to prevent performance degradation on mutation-heavy pages (SPAs, React, live data).
- **Token caching:** JIT engine now caches the last DOM token set and skips recompilation when tokens haven't changed between mutations, avoiding redundant CSS generation.
